# 詰碁道場

ブラウザで遊べる詰碁(囲碁の死活問題)のWebアプリです。入門から有段まで全100問を収録しています。

## 使い方

`index.html` をブラウザで開くだけで動きます。インストールやサーバーは必要ありません(フォントの読み込みにだけインターネット接続を使います)。

1. 盤上をクリック(スマホならタップ)して黒石を打ちます。
2. 正解の手なら白が応じるので、そのまま手順を続けます。最後まで打ち切ると「正解!」と表示されます。
3. 間違えると白がとがめる手を打ちます。「やり直す」でもう一度挑戦できます。

盤の左と上の太い線が盤の端(隅)です。すべて黒番の問題です。

## 収録問題

| レベル | 問題数 | 内容 |
|---|---|---|
| 入門 | 6問 | アタリで取る、直三・曲三の急所 |
| 初級 | 8問 | 丁四・刃五・花五の急所、一線のハネと下がり |
| 中級 | 18問 | 下がってから置く、置き石をアタリにしながら生きる など |
| 上級 | 40問 | 黒3〜5手の手順、捨て石や取り返しを含む問題 |
| 有段 | 28問 | 手順が長く、捨て石など筋の良さが必要な問題 |

問題の種類は次の3つです。

- 黒先 白死:白を殺す
- 黒先 活き:黒が生きる(セキも含む)
- 黒先:白石を取る

## 機能

- **ヒント**:1回押すとヒントの文章、2回押すと今打つべき点に印が付きます。
- **答えを見る**:正解手順を自動で再生します。
- **やり直す**:問題を最初の状態に戻します。
- **問題一覧**:レベル別に並んでいて、正解した問題は黒丸で表示されます。
- **記録の保存**:正解の記録はブラウザ(localStorage)に保存されます。急所の印を見た問題や答えを見た問題は、正解として記録されません。一覧下の「記録を消す」でリセットできます。
- スマホ表示とダークモードに対応しています。

## 問題の作り方について

正解に誤りがないように、すべての問題を死活ソルバー(探索プログラム)で検証しています。ソルバーは取り・自殺手禁止・コウのルールを実装しています。各問題が次の条件を満たすことを確認しました。

- 黒が正しく打てば目的を達成できる
- 白が先に打つと目的を達成できない(問題として成り立っている)
- 正解の第一手が1つに決まる(入門の1問のみ正解が2つあります)

正解手順の分岐と、間違えたときの白の応手も、ソルバーの結果から作っています。

注意点:

- 中級・上級・有段のうち71問は、ソルバーで自動生成した候補から選んだ問題です。実戦ではあまり見ない石の配置も一部含まれます。
- 上の71問のヒント文は、正解の手の形(ハネ、置き、捨て石など)から自動で作っています。
- 判定は盤上に表示している範囲だけで行っています。外側の石は十分に強い(取られない)ものとして扱っています。

## ファイル構成

`index.html` 1ファイルに、画面(HTML/CSS)、碁のルール判定(JavaScript)、問題データ100問がすべて入っています。

問題データは `const DATA=[...]` の配列で、1問ごとに次の項目があります。

- `lv`:レベル(0=入門 〜 4=有段)
- `mode`:`kill`(白死)、`live`(活き)、`capture`(取る)
- `rows`:盤面。`X`=黒、`O`=白、`.`=空点、`,`=判定範囲外の空点
- `tree`:正解手順の木
  - `ok` には正解の手と、それに対する白の応手が入ります。
  - `ng` には不正解の手と、それをとがめる白の手が入ります。
- `hint`:ヒント文
